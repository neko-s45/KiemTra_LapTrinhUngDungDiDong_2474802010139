# KiemTra_LapTrinhUngDungDiDong_MSSV

Project Android Kotlin dùng template **Empty Views Activity**, giao diện XML và `findViewById`.

> Trước khi nộp: thay `MSSV` bằng mã số sinh viên thật trong tên project/repository, `rootProject.name`, `app_name`, `namespace`, `applicationId` và package Kotlin. Không dùng nguyên chữ `MSSV`.

Các nhánh bài thi: `cau-1` (Login + validation), `cau-2` (Intent + Profile), `cau-3` (ListView + ArrayAdapter).
